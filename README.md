# Simple Interest Calculator

## Description
This project calculates simple interest based on the principal amount, annual interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- **Principal:** The initial amount of money.
- **Rate:** The annual interest rate in percentage.
- **Time:** The duration in years.

## Example
- Principal: 1000
- Rate: 5%
- Time: 2 years

**Calculation:** (1000 × 5 × 2) / 100 = 100

**Simple Interest:** 100

**Total Amount:** 1100

## Technologies Used
- HTML
- CSS
- JavaScript

## How It Works
Enter the principal amount, interest rate, and time period. The calculator uses the simple interest formula to calculate the interest and total amount.
